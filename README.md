# FrontController en Spring Boot

Esta tarea implementa el patron **FrontController** usando **Spring Boot y Thymeleaf**

## Caracteristicas

- Recibe solicitudes a traves del **FrontController**
- Usa `DispatcherServerlet` para dirigir las peticiones
- Muestra una pagina html con opciones dinamicas
